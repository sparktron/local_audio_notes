Import recordings

Files are copied into private local storage and validated by content, not extension. The original file on disk is never modified or deleted.

Import one recording

Processing

Model, language, speaker-count and GPU options are on the settings page.

Transcribe ignores the attachment for notes. Align uses the supplied timed text and audio for word alignment and speakers. Compare creates notes from a new transcription, not the attachment. Untimed TXT cannot currently be used as the notes source; no timestamps are guessed.

Import a folder

Select a folder of recordings. WAV, M4A, MP3 and FLAC files in the folder and its subfolders are imported individually. Existing audio is skipped by content, even if its filename has changed or it has a transcript attached. Other files are ignored. Folder imports transcribe audio and do not attach transcripts.
